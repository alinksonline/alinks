3. ARCHITECTURE RULES (NON-NEGOTIABLE)
================================================================================

Read src/ARCHITECTURE.txt before every feature.

LAYER IMPORT RULES
  core/      → imports nothing from platform, tenant, components, app
  platform/  → imports core only
  tenant/    → imports core + platform
  components/ui/ → dumb primitives only; NO database calls
  app/       → route composition; keep domain logic in platform/ or tenant/

DATA OWNERSHIP (LOCKED — baseline 5D)
  Artix PostgreSQL  → tenant config, pages, theme, billing refs, legal logs
  Google Sheets     → customer/order/booking PII (tenant-owned)
  Tenant Supabase   → optional BYO PII store (Phase 4)
  NEVER add client_pii, customers, patients, orders tables to platform DB

ROUTING (Q001 LOCKED)
  Basic/Free     → alinks.online/[handle]
  Pro/Enterprise → [handle].alinks.online
  Custom domain  → additive CNAME (Phase 2 wizard)
  Reserved handles → see src/core/constants/limits.ts RESERVED_HANDLES

PUBLISH GATE (Q019 LOCKED — implement Phase 1)
  Required before isPublished = true:
    - PLATFORM_TOS + PLATFORM_PRIVACY at signup
    - TENANT_TOS_PUBLISHED + TENANT_PRIVACY_PUBLISHED
    - Active subscription OR valid trial (Q035)
  Log every acceptance in legal_acceptances table
  Inject Doc 03 End-User Notice on all public pages
