1. PRODUCT PRINCIPLE
================================================================================

  ONE booking engine, MANY industry profiles.

  Bookings industry family covers time-and-resource reservation:
    • People resources (doctor, lawyer, consultant, therapist)
    • Space resources (clinic room, consultation room, banquet hall, lawn)
    • Service packages (consultation type, hall package, ceremony slot)

  SELF-AWARE from Superadmin industry type + purchased modules
  (same pattern as food_industry).

  BILLING LAYERS
    LAYER 1 — Website plan: mini-site, services list, Book CTA, WhatsApp
    LAYER 2 — Booking modules: core calendar, clinic pack, legal pack,
              venue pack, deposits, reminders, multi-location
    LAYER 3 — Industry type / subtype: fields, compliance, seeds

  Platform Billing = Artix SKUs (plans/modules).
  Tenant Checkout = client pays professional/venue (tenant Razorpay/COD/WA).

3. MODULES (FIRST-CLASS)
================================================================================

  book.core              Appointments core (slots, calendar, services)
  book.clinic            Clinic/healthcare compliance + patient fields
  book.professional      Professional consult packaging
  book.legal             Lawyer consult + engagement-lite rules
  book.venue             Banquet / function hall date capacity packages
  book.payments          Optional deposits / pay-to-confirm (tenant PG)
                         FREE client bookings always allowed without this
  book.reminders         SMS/email/WA reminders + no-show policy tools
  book.multilocation     Extra branches/clinics/halls (5–10% off extra)
  google.calendar        FREE platform capability (not a paid module):
                         tenant Gmail/Workspace → Google Calendar sync
                         (push + pull busy; see 19-*.txt). All industries
                         where events apply — including food catering.

  Website plan alone = catalogue + “Book on WhatsApp” / simple enquiry.
  book.core unlocks real slot booking on ALINKS.
  Google Calendar is free once they have events to sync.

================================================================================
4. HARD RULES
================================================================================

  • No long-term patient/client case files on platform Postgres.
  • Clinic live booking requires license gate (regulated).
  • No online diagnosis / Rx selling in MVP.
  • Lawyer module = consultation booking, not court case CMS v1.
  • Venue module = hall reservation; food catering for events may link
    later to food_industry catering module — separate purchase.
  • Cloud restaurant dine-in QR is FOOD not BOOKINGS venue.
  • FREE CLIENT BOOKINGS: tenants may use full bookings (slots, calendar,
    Google Calendar, reminders) without charging end-clients. Charging is
    opt-in via book.payments / per-service toggle — never required.
  • GOOGLE CALENDAR SYNC: free for all applicable industries (bookings +
    catering + any scheduled work). Never an extra-cost add-on.

================================================================================
5. SHARED VS DISTINCT
================================================================================

  SHARED ENGINE
    Services/resources, availability, slots, buffers, blackouts,
    booking status: requested → confirmed → completed → cancelled/no_show

  DISTINCT BY TYPE
    Clinic: license, patient tab, visit reason (no diagnosis storage)
    Lawyer: consult type, duration, confidentiality notice
    Consult: generic professional
    Venue: date-first, package (half-day/full-day), guest capacity, deposit
