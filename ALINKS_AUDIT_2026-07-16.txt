2. FINDINGS (SEVERITY ORDERED)
================================================================================

--------------------------------------------------------------------------------
HIGH
--------------------------------------------------------------------------------

  H1. create-order industry gate is optional by identity
      File: src/app/api/create-order/route.ts
      Gate runs only if body.handle OR body.businessId is provided.
      If client omits both, order can be created without industry check.
      Fix: require handle or businessId when commerce is tenant-scoped;
           or reject when neither is present for public checkout flows.
      Verify all createOrderViaApi call sites pass identity.

  H2. Large uncommitted industries surface vs origin/main
      Working tree has migrations 0007–0012, industries-docs, many routes
      not necessarily on production. Risk: “code works locally, prod is old”
      or “prod has code without migrations applied.”
      Fix: commit in logical PRs; run db:migrate on each env; redeploy.

  H3. Google Calendar not production OAuth
      Stub connect records connection without real Calendar API when no
      refresh token (src/platform/integrations/google-calendar.ts).
      Fine for dev; do not market “Google Calendar sync live” yet.

--------------------------------------------------------------------------------
MEDIUM
--------------------------------------------------------------------------------

  M1. appointment_holds.notes can become soft PII
      Schema allows free-text notes on platform. If UI ever puts customer
      phone/name in notes, data-boundary drifts.
      Fix: never write customer identity into notes; keep Sheets-only.

  M2. DPDP status doc outdated (legal/21-*.txt dated 2026-07-08)
      Claims rights tooling missing; guardrails now report grievance/delete/
      export present. Refresh DPDP audit after lawyer pass.

  M3. Module catalog SKUs vs industries-docs full matrix
      modules.ts lists core Presence + book + food.menu + retail.storefront.
      Docs describe many more paid modules (kitchen, wholesale, etc.) as later.
      Align Superadmin “stub | later” labels with reality (partially done).

  M4. Finance called-off OK in registry; pharmacy selectable?
      pharmacy in INDUSTRY_GROUPS as parked — ensure onboarding cannot fully
      open unapproved pharmacy commerce without gates.

  M5. Lint warning
      linktree-stack-editor.tsx react-hooks/exhaustive-deps (low risk).

  M6. Superadmin copy mentions “à la carte” in explaining never to use it

      only even in admin help text for consistency.
