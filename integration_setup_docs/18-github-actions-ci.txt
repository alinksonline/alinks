================================================================================
18 — GITHUB ACTIONS CI
================================================================================

GOAL
  Run automated tests, lint, and production build on every push and PR to main.
  Catch broken builds before Vercel deploys.

FILE
  .github/workflows/ci.yml

VIEW RUNS
  https://github.com/alinksonline/alinks/actions

--------------------------------------------------------------------------------
WHAT CI RUNS
--------------------------------------------------------------------------------
  On: push to main, pull_request to main

  Steps:
    1. checkout code
    2. setup Node.js 20 with npm cache
    3. npm ci
    4. npm run guardrails:scan  (compliance & security — fails on critical)
    5. npm run test             (pretest also runs guardrails:scan)
    6. npm run lint
    7. npm run build

  Build env (CI-only placeholders — no secrets required):
    NEXT_PUBLIC_APP_URL=https://alinks.vercel.app
    NEXT_PUBLIC_ROOT_DOMAIN=alinks.vercel.app
    NEXT_PUBLIC_PLATFORM_HOST=alinks.vercel.app
    NEXT_PUBLIC_MARKETING_HOST=alinks.vercel.app

  DATABASE_URL is NOT required for CI build (routes use dynamic where needed).

--------------------------------------------------------------------------------
STEP 1 — ENABLE ACTIONS (default on public repos)
--------------------------------------------------------------------------------
  GitHub → alinksonline/alinks → Settings → Actions → General
  Allow: "Allow all actions and reusable workflows"

--------------------------------------------------------------------------------
STEP 2 — FIRST RUN
--------------------------------------------------------------------------------
  Push any commit to main:
    git add .
    git commit -m "trigger ci"
    git push origin main

  GitHub → Actions tab → watch "CI" workflow

--------------------------------------------------------------------------------
STEP 3 — PR WORKFLOW
--------------------------------------------------------------------------------
  1. Create branch: git checkout -b feature/my-change
  2. Push: git push origin feature/my-change
  3. Open Pull Request on GitHub
  4. CI runs on PR — must be green before merge
  5. Merge to main → Vercel auto-deploys (doc 02)

--------------------------------------------------------------------------------
STEP 4 — OPTIONAL GITHUB SECRETS
--------------------------------------------------------------------------------
  Repo → Settings → Secrets and variables → Actions → New repository secret

  Only if you extend CI later:

  | Secret        | Use case                                      |
  |---------------|-----------------------------------------------|
  | DATABASE_URL  | Run db:migrate in CI before deploy            |
  | VERCEL_TOKEN  | CLI deploy from Actions (usually not needed)  |
  | NEON_API_KEY  | Branch database for preview envs              |
  | CODERABBIT_API_KEY | Optional CLI review in PRs (doc 23)    |

  Vercel GitHub App handles deploy without VERCEL_TOKEN.

  CodeRabbit GitHub App reviews PRs automatically (no secret needed).
  Optional: .github/workflows/coderabbit-review.yml uses CODERABBIT_API_KEY.

--------------------------------------------------------------------------------
STEP 5 — OPTIONAL: MIGRATION JOB (future)
--------------------------------------------------------------------------------
  Add job after build passes:

    - name: Migrate production
      if: github.ref == 'refs/heads/main'
      env:
        DATABASE_URL: ${{ secrets.DATABASE_URL }}
      run: npm run db:migrate

  Only add when you want schema changes applied automatically on merge.
  Safer early on: run migrations manually after deploy (doc 04).

--------------------------------------------------------------------------------
STEP 6 — DEPENDABOT (recommended)
--------------------------------------------------------------------------------
  GitHub → alinksonline/alinks → Settings → Code security
  Enable:
    - Dependabot alerts
    - Dependabot security updates

  Optional: add .github/dependabot.yml for weekly npm updates.

--------------------------------------------------------------------------------
TROUBLESHOOTING
--------------------------------------------------------------------------------
  | Failure              | Fix                                              |
  |----------------------|--------------------------------------------------|
  | test fails           | Run npm run test locally; fix failing spec       |
  | lint fails           | Run npm run lint locally                         |
  | build fails          | Run npm run build locally; check env vars        |
  | npm ci lock mismatch | Commit package-lock.json after npm install       |

--------------------------------------------------------------------------------
VERIFY
--------------------------------------------------------------------------------
  [ ] Latest push to main shows green CI badge
  [ ] PR shows required checks passing
  [ ] Broken commit would fail before Vercel deploy
