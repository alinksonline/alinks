--------------------------------------------------------------------------------

  | Field            | Value                                      |
  |------------------|--------------------------------------------|
  | Template name    | ALINKS_Signup_OTP                          |
  | Template ID      | 6a4d3880e8e89020f0004466 (from dashboard) |

--------------------------------------------------------------------------------
STEP 4 — HOW CODE WORKS
--------------------------------------------------------------------------------
  Send (user clicks "Send OTP"):
    POST https://control.msg91.com/api/v5/otp
      ?authkey=...&template_id=...&mobile=91xxxxxxxxxx
    → src/platform/sms/msg91.ts → sendLoginOtp()
    → src/app/actions/auth.ts → sendOtpAction()

  Verify (user enters OTP):
    GET https://control.msg91.com/api/v5/otp/verify
      ?authkey=...&mobile=91xxxxxxxxxx&otp=xxxx
    → verifyLoginOtp() → createSession()

  Fallback (no MSG91 env vars + NODE_ENV=development):
    DEV_OTP from .env still works (local only)

  Production without MSG91:
    Login blocked with "SMS login is not configured"

--------------------------------------------------------------------------------
TROUBLESHOOTING
--------------------------------------------------------------------------------
  | Symptom              | Fix                                                |
  |----------------------|----------------------------------------------------|
  | SMS not received     | API may return success but SMS fails — see DLT row |
  | Failed report 400    | "Template ID Missing or Invalid" → map DLT ID in   |
  |                      | MSG91 → OTP → ALINKS_Signup_OTP → Edit → DLT field |
  |                      | Save → Test DLT → test SMS must arrive on phone    |
  | API Failed 400       | MSG91_OTP_TEMPLATE_ID wrong — NOT the Auth Key     |
  | 401 / auth error     | Regenerate Auth Key; update env                    |
  | Invalid template     | Copy Template ID from AlinkOTP row exactly         |
  | Still uses dev OTP   | Both MSG91 vars must be set; restart dev server    |
  | OTP verify fails     | Wait 30s; request new OTP; check 4-digit code      |
