TABLE: legal_acceptances
------------------------
  id              UUID PK
  tenant_id       FK (nullable for customer session acceptances)
  customer_session_id  (nullable — for checkout/booking)
  doc_type        ENUM (see below)
  doc_version     VARCHAR (e.g., "1.0")
  accepted_at     TIMESTAMP
  ip_address      VARCHAR
  user_agent      TEXT
  metadata        JSONB (optional: order_id, product_id)

DOC_TYPE ENUM
-------------
  PLATFORM_TOS
  PLATFORM_PRIVACY
  PLATFORM_AUP
  PAYMENT_ADDENDUM
  DATA_STORAGE_ADDENDUM
  TENANT_TOS_PUBLISHED      -- tenant confirms published
  TENANT_PRIVACY_PUBLISHED
  GOOGLE_CONNECT
  SUPABASE_CONNECT
  GROCERY_LICENCE_CHECKBOX
  PHARMACY_LICENCE_CHECKBOX
  CLINIC_LICENCE_CHECKBOX
  AFFILIATE_DISCLOSURE
  AI_CONTENT_REVIEW
  CUSTOMER_CHECKOUT
  CUSTOMER_SALON_BOOKING
  CUSTOMER_CLINIC_BOOKING
  CUSTOMER_COD
  CONSENT_WITHDRAWAL        -- optional processing withdrawn (ads)
  TENANT_BYO_GATEWAY        -- connected own Razorpay for shop sales
  CREATOR_PARTNER

PUBLISH GATE (tenant mini-site public)
---------------------------------------
REQUIRED before publish = TRUE:
  - PLATFORM_TOS (at signup)
  - PLATFORM_PRIVACY (at signup)
  - TENANT_TOS_PUBLISHED
  - TENANT_PRIVACY_PUBLISHED
  - Active paid subscription OR valid trial per Q035

OPTIONAL / SECTOR:
  - PHARMACY_LICENCE_CHECKBOX + verify APPROVED → pharmacy vertical
  - CLINIC_LICENCE_CHECKBOX + verify APPROVED → clinic booking live
  - PAYMENT_ADDENDUM → reserved if Artix-facilitated shop PayFac is revived
  - TENANT_BYO_GATEWAY (product ack) → enable online checkout with own Razorpay
    (Q005 re-lock 2026-07: customer money settles to tenant account; not Artix GMV)

Q005 PAYMENT DOMAINS (2026-07)
------------------------------
  PLATFORM BILLING (tenant → Artix): Artix Razorpay — subscriptions / modules
  TENANT STOREFRONT (customer → shop): tenant BYO Razorpay keys (encrypted secret)
  COD: default ON (Q020); tenant liability for COD disputes

CUSTOMER FLOW
-------------
  CUSTOMER_CHECKOUT → required if Pro payment
  CUSTOMER_CLINIC_BOOKING → emergency disclaimer + clinic T&C
  CUSTOMER_SALON_BOOKING → package pay + cancellation policy
